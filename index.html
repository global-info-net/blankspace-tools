What Is an Invisible Character?

An invisible character is a Unicode character that occupies space in text but does not display like an ordinary letter, number or symbol. It can be copied and pasted into compatible applications and text fields.

This free invisible character generator provides a ready-to-copy Unicode Hangul Filler character (U+3164). You can use it for supported gaming usernames, social media profiles, messaging applications and other text fields.

Character information

Unicode: U+3164

Character name: Hangul Filler

Copyable output: One invisible-style Unicode character.

Where Can You Use Invisible Characters?

Invisible-style Unicode characters may work in gaming usernames, profile names, social media bios, chat messages and other applications that accept the character.
